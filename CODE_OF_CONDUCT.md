# Code of Conduct

Idle Hero should be a welcoming project for contributors with different backgrounds and experience levels.

## Expected Behavior

- Be respectful and constructive in issues, pull requests, reviews, and discussions.
- Assume good intent, especially when giving or receiving feedback.
- Keep criticism focused on the code, design, documentation, or process.
- Help newcomers understand the project and its conventions.

## Unacceptable Behavior

- Harassment, intimidation, personal attacks, or discriminatory language.
- Repeated off-topic disruption of project discussions.
- Publishing private information without permission.
- Dismissing contributors based on identity, background, or experience level.

## Enforcement

Maintainers may edit, hide, or remove comments and close issues or pull requests that violate this code of conduct. Serious or repeated violations may lead to a ban from participating in the project.

If you need to report a concern, contact a project maintainer privately when possible. If private contact is not available yet, open a minimal issue asking for a maintainer contact without posting sensitive details publicly.

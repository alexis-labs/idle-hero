# Security Policy

Idle Hero is currently a client-side prototype. It does not include authentication, payments, multiplayer, backend APIs, or server-side storage.

## Supported Versions

Security fixes target the latest code on the default branch.

## Reporting a Vulnerability

If you find a vulnerability or a save-corruption issue with security impact, please avoid posting exploit details publicly. Contact a maintainer privately when possible, or open a minimal issue asking for a private contact path.

Please include:

- A short description of the problem.
- Steps to reproduce it.
- Browser and OS details when relevant.
- Whether the issue affects fresh saves, imported saves, or existing saves only.
